# API Reference

Complete reference documentation for all LuxSDK APIs, interfaces, and types.

## Core SDK

### sdk.LuxSDK

The main SDK interface providing comprehensive blockchain development capabilities.

```go
type LuxSDK struct {
    // Contains filtered or unexported fields
}
```

#### Methods

##### New
```go
func New(cfg *config.Config) (*LuxSDK, error)
```
Creates a new instance of the Lux SDK.

**Parameters:**
- `cfg` - SDK configuration (uses default if nil)

**Returns:**
- `*LuxSDK` - SDK instance
- `error` - Error if initialization fails

**Example:**
```go
sdk, err := sdk.New(&config.Config{
    Network: &config.NetworkConfig{
        NetworkID: 31337,
    },
})
```

##### Networks
```go
func (sdk *LuxSDK) Networks() *network.NetworkManager
```
Returns the network manager for network operations.

##### Blockchains
```go
func (sdk *LuxSDK) Blockchains() *blockchain.Builder
```
Returns the blockchain builder for blockchain operations.

##### LaunchNetwork
```go
func (sdk *LuxSDK) LaunchNetwork(
    ctx context.Context,
    networkType string,
    numNodes int,
) (*network.Network, error)
```
Launches a network with specified parameters.

**Parameters:**
- `ctx` - Context for cancellation
- `networkType` - Type of network ("local", "testnet", "mainnet")
- `numNodes` - Number of nodes to launch

##### CreateAndDeployBlockchain
```go
func (sdk *LuxSDK) CreateAndDeployBlockchain(
    ctx context.Context,
    params *BlockchainParams,
) (*blockchain.Blockchain, error)
```
Creates and deploys a blockchain to a network.

## VM Interfaces

### vm.VM

Base VM interface that all VMs must implement.

```go
type VM interface {
    Initialize(
        ctx context.Context,
        config *Config,
        db database.Database,
        genesis []byte,
    ) error

    BuildBlock(ctx context.Context) (Block, error)
    VerifyBlock(ctx context.Context, block Block) error
    AcceptBlock(ctx context.Context, block Block) error
    RejectBlock(ctx context.Context, block Block) error

    GetBlock(ctx context.Context, id ids.ID) (Block, error)
    SetPreference(ctx context.Context, id ids.ID) error

    Shutdown(ctx context.Context) error
    HealthCheck(ctx context.Context) error
}
```

### vm.Block

Block interface for VM blocks.

```go
type Block interface {
    ID() ids.ID
    ParentID() ids.ID
    Height() uint64
    Timestamp() int64
    Bytes() []byte

    Verify(ctx context.Context) error
    Accept(ctx context.Context) error
    Reject(ctx context.Context) error
}
```

### vm.Transaction

Transaction interface for VM transactions.

```go
type Transaction interface {
    ID() ids.ID
    Bytes() []byte
    Size() int

    Verify(ctx context.Context) error
    Execute(ctx context.Context, state State) error
}
```

## Consensus Interfaces

### consensus.Engine

Base consensus engine interface.

```go
type Engine interface {
    Start(ctx context.Context, requestID uint32) error
    Stop(ctx context.Context) error

    HealthCheck(ctx context.Context) (interface{}, error)
    IsBootstrapped() bool

    // Block processing
    BuildBlock(ctx context.Context) (Block, error)
    VerifyBlock(ctx context.Context, block Block) error
    AcceptBlock(ctx context.Context, block Block) error
}
```

### consensus.BFTEngine

Byzantine Fault Tolerant consensus engine.

```go
type BFTEngine interface {
    Engine

    // BFT-specific methods
    Propose(ctx context.Context, block Block) error
    Prevote(ctx context.Context, blockID ids.ID) error
    Precommit(ctx context.Context, blockID ids.ID) error

    // View change
    InitiateViewChange(newView uint32) error
    ProcessViewChange(msg *ViewChangeMsg) error
}
```

## Event System

### Events

```go
type Event interface {
    Type() EventType
    Timestamp() time.Time
    Data() interface{}
}
```

### Event Types

```go
const (
    EventBlockAccepted EventType = "block.accepted"
    EventBlockRejected EventType = "block.rejected"
    EventTxAccepted    EventType = "tx.accepted"
    EventTxRejected    EventType = "tx.rejected"
    EventNodeJoined    EventType = "node.joined"
    EventNodeLeft      EventType = "node.left"
)
```

### Event Subscription

```go
// Subscribe to events
sub := sdk.Subscribe(EventBlockAccepted)
defer sub.Unsubscribe()

for event := range sub.Events() {
    log.Printf("Block accepted: %v", event.Data())
}
```
